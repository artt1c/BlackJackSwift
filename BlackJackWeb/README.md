# Блекджек — Web-клієнт

Браузерний клієнт для багатокористувацького блекджека. Говорить тим самим
протоколом, що й iOS-додаток (`BlacjackMobile`), і грає **разом** з ним за тими
самими столами (спільний сервер `BlackjackServer`, спільні моделі з
`SharedModels`).

## Вимоги

- Node.js ≥ 18 (перевірено на v26)
- Vapor-сервер запущено на `127.0.0.1:8080`

## Запуск (розробка)

```bash
npm install
npm run cards      # копіює картинки карт з iOS-каталогу в public/cards
npm run dev        # Vite dev-сервер на http://localhost:5173
```

Dev-сервер проксіює `/lobbies` (REST) та `/ws` (WebSocket) на `127.0.0.1:8080`,
тому клієнт працює з відносними URL без окремої настройки CORS.

## Білд (продакшн-артефакт)

```bash
npm run build      # tsc --noEmit + vite build → dist/
npm run preview    # локальний перегляд зібраного dist/
```

## Стек

- React 18 + TypeScript (strict) + Vite 5
- Власний казино-стиль (SCSS-ОК, CSS-змінні) — темний фон + золото, зелене сукно
- Карти: перевикористовують PNG-арт iOS-додатка (без дублювання коду)

## Протокол

Типи й повідомлення у `src/protocol.ts` в точності повторюють `SharedModels`
(`MultiplayerModels.swift` + `SharedModels.swift`). Розшифрування протоколу:

- `Card.rank` шифрується як `Int`: 11 = туз, 12 = валет, 13 = дама, 14 = король.
- `Card.isHidden` — маскована карта (суперники / дилер під час роздачі).
- Сервер сам маскує чужі руки й очки дилера (`makeTableState` → `maskedState`),
  тож клієнт лише відображає отримане; підглянути неможливо.
